# Title



Research Proposal: Writing Process and Tools



# Summary



This section goes through the writing style that was used for this paper, which is a combination of paper and pencil outlining and digital management of files and Git version control being executed through Windows PowerShell.



# Process Description



My writing process is a combination of a physical paper outline and then a digital terminal workspace. I began by using paper and pencil to break up my ideas into sections and bullet points, which allowed me to organize my thoughts. I connect ideas together to be able to form the major topics from the minor ideas. To handle the computing aspect of the assignment, I used Windows PowerShell to navigate through my local directories and to execute Git commands to manage my repository.
